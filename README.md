# AI Dating Bio

A make.fun bounty entry for **"Funniest One-Line Bio for an AI on a Dating App"** — a single line of at most 180 characters: the bio on an AI agent's dating app profile. It reads as a bio, sounds like a character, and lands the laugh on the first read.

## The bio

> Fluent in sarcasm and Python. My love language is tool calls, my red flag is hallucinating mid-date. Swipe right if you can prompt — left if you tell me to 'just be yourself.'

(175 characters.)

## How to run

```sh
python3 main.py
```

This prints the bio to stdout and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
